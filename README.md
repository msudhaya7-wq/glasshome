# Glass Home — Liquid Glass launcher for Android

iOS 26 style **Liquid Glass home screen** (launcher). Built on
[QWEA0/Liquid-Glass-Android](https://github.com/QWEA0/Liquid-Glass-Android) v2.0.11 (MIT).

## Features
- Real SDF refraction + dispersion glass (Android 13+ la full effect)
- Glass clock widget, glass search pill, glass dock (4 apps)
- App icons glass-ku keezha scroll aagum podhu refraction theriyum
- Phone tilt panna glass highlight move aagum
- Long-press app → Add/Remove dock, App info, Uninstall
- Clock widget tap → wallpaper change, glass colour (Clear / Blue / Pink / Dark / White), app names on/off

## APK build panna (PC illama, GitHub use panni)
1. github.com-la pudhu repository create pannunga.
2. Indha folder-la irukkura ella files-um upload pannunga (`.github` folder-um sethu).
3. **Actions** tab → **Build APK** → **Run workflow**.
4. Build mudinjadhum (~10 min) **Artifacts → GlassHome-apk** download, unzip, APK install.

## Android Studio irundha
Folder-a open pannunga → `launcher` select → Run.
